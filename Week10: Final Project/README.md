# Goldbach Lab
### A Computational Laboratory for Goldbach's Conjecture

**Goldbach Lab** is a computational mathematics project that explores Goldbach's conjecture using C, Python, statistical analysis, and data visualization.

Goldbach's conjecture states that every even integer greater than 2 can be expressed as the sum of two prime numbers. Although extensive computational evidence supports the conjecture, a general mathematical proof remains unknown.

This project investigates the number of Goldbach partitions for even integers from 4 through 100,000. Rather than attempting to prove the conjecture, it focuses on computation, data analysis, independent verification, and the exploration of numerical patterns.

## Mathematical Background

For an even integer \(N\), let \(G(N)\) denote the number of unordered pairs of primes satisfying

\[
p+q=N,\qquad p\leq q.
\]

For example,

\[
10=3+7=5+5,
\]

so \(G(10)=2\).

Studying \(G(N)\) across a finite range provides a way to explore how Goldbach partition counts vary as \(N\) increases.

## Project Workflow

The project follows four main stages:

1. **Computation in C:** Calculate Goldbach partition counts for even integers.
2. **Data storage:** Save the results in a CSV file.
3. **Analysis in Python:** Calculate summary statistics and independently recompute the partition counts.
4. **Visualization:** Generate plots to explore the distribution and variation of the results.

## How to Run

You need GCC, Python 3, and the Python libraries required by `analyze.py`.

Compile and run the C program:

```bash
gcc goldbach.c -o goldbach
./goldbach
```

Run the Python analysis:

```bash
python3 analyze.py
```

Run the C program before the Python script when regenerating the dataset, because the analysis depends on the CSV file produced by the computation.

## Design Choices

The project separates computation from analysis. C handles the main numerical computation, while Python provides statistical analysis and visualization. CSV serves as a simple interface between the two stages, making the data easy to inspect and reuse.

Independent verification is another important design choice. The Python script uses a prime sieve to recompute the partition counts and compare them with the C output. This cross-check can help identify implementation errors, although agreement between two programs does not constitute a formal proof of correctness.

The three visualizations serve different purposes: the scatter plot displays individual observations, the frequency plot summarizes the distribution, and the block-average plot highlights changes across ranges.

## Limitations

This project examines a finite range of even integers. Its results provide computational evidence for the tested cases but cannot prove that Goldbach's conjecture holds for every even integer greater than 2. The independent comparison also checks consistency between implementations rather than replacing a mathematical proof.

## Motivation

Goldbach Lab is an exploration of how programming and data analysis can support mathematical investigation. It combines C programming, Python, reproducible data processing, visualization, and computational verification to examine a classical open problem in number theory.
