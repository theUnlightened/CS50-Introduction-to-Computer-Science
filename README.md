## About This Repository

This repository documents my learning journey through [CS50x: Introduction to Computer Science](https://cs50.harvard.edu/x/2026/), Harvard University's introductory computer science course taught by David J. Malan.

CS50x introduced me to the fundamental ideas behind computer science: computational thinking, algorithms, data structures, memory management, databases, and software development.

Throughout this journey, I have worked on programming exercises and practical projects, using code to solve problems and explore the connections between computer science, mathematics, and data.

My objective is not simply to finish assignments. I want to understand why programs work, how algorithms are designed, and how to approach unfamiliar problems independently.

> Learning computer science means learning how to think, not just learning how to code.

## Key Features

## My Work

### 1. C Programming

C has been one of the central parts of my introduction to computer science.

Writing C programs has helped me develop a more precise understanding of how programs handle data, control execution, and implement algorithms.

My work includes programming exercises and independent solutions to computational problems.

Concepts I have explored include:

- Variables, data types, operators, and control flow
- Functions, arrays, and strings
- Input handling and debugging
- Algorithm design and implementation
- Dynamic memory allocation and data storage

I aim to understand the reasoning behind each solution rather than relying on code that I cannot explain.

### 2. Python and Statistical Analysis

Python allows me to investigate data and computational results at a higher level of abstraction.

In my statistical analysis work, I write Python code to process data and calculate results. I have also used AI assistance for plotting components.

I distinguish between the analysis code I wrote and the visualization code developed with AI assistance.

This workflow helps me connect programming with quantitative reasoning and data interpretation.

### 3. SQL and Database Exercises

Through CS50's SQL material, I explored relational databases and structured queries.

This work introduces important ideas such as:

- Retrieving and filtering records
- Organizing information in relational tables
- Writing queries to answer questions about data
- Understanding how structured data supports applications

### 4. Web Development Exercises

The web development portion of CS50 introduces the technologies used to build interactive websites and applications.

I have worked with introductory exercises involving:

- HTML for page structure
- CSS for presentation and layout
- JavaScript for interactive behavior

These exercises broaden my understanding beyond command-line programs and demonstrate how different technologies work together in software development.

### 5. Independent Computational Experiments

I am interested in using programming to explore mathematical and computational problems.

For me, these experiments provide a bridge between mathematical reasoning and implementation. They also create opportunities to test ideas, analyze results, debug unexpected behavior, and improve a solution.

I intend to continue developing this part of my work as my programming and mathematical foundations grow.

## My Approach to Problem-Solving

I treat programming as an iterative process rather than a one-step exercise.

1. **Understand the problem:** Identify the inputs, outputs, constraints, and underlying concepts.
2. **Design an approach:** Break the problem into smaller parts and develop an algorithm.
3. **Implement the solution:** Translate the algorithm into code.
4. **Test and debug:** Investigate errors and verify the program's behavior.
5. **Evaluate the result:** Consider correctness, clarity, efficiency, and alternative approaches.
6. **Reflect and document:** Record what I learned and identify concepts that need further study.

This process helps me develop skills that extend beyond individual assignments.

## AI-Assisted Development

I use AI tools selectively to support learning and development. Depending on the task, they may help explain unfamiliar concepts, discuss possible approaches, or assist with selected implementation components.

I also aim to be transparent about my contributions.

In my Python statistical analysis work, for example:

- I wrote the statistical analysis code myself.
- AI assisted with the plotting component.
- I reviewed the generated plotting code and used it as part of my project workflow.
- I distinguish my own implementation from AI-assisted work.

I see AI as a tool that can support learning, not a replacement for understanding the code or reasoning behind a solution.
