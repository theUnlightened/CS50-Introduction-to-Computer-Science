# CS50’s Introduction to Computer Science

This repository documents my learning journey through [CS50x — Introduction to Computer Science](https://cs50.harvard.edu/x/), Harvard University's introductory computer science course taught by David J. Malan.

My goal is to build a strong foundation in computer science, develop systematic problem-solving skills, and understand not only how to write programs, but also why they work.

## About the Course

CS50x introduces fundamental concepts in computer science through programming assignments, problem sets, and practical projects. Throughout the course, I explore algorithms, data structures, memory management, databases, and web development.

**Topics covered include:**

- **Computational Thinking:** Binary, abstraction, and problem decomposition
- **C Programming:** Variables, functions, loops, arrays, pointers, and memory management
- **Algorithms:** Searching, sorting, algorithmic efficiency, and computational complexity
- **Data Structures:** Linked lists, hash tables, tries, and other fundamental structures
- **Python:** Programming fundamentals, data processing, and problem-solving
- **SQL:** Relational databases and queries
- **Web Development:** HTML, CSS, JavaScript, and Flask
- **Software Development:** Debugging, code quality, testing, and project design

## Learning Approach

I approach programming as an iterative process:

1. Understand the problem and identify its requirements.
2. Design an algorithm before implementing it.
3. Translate the solution into code.
4. Test the implementation and investigate errors.
5. Refine the solution for correctness, clarity, and efficiency.
6. Reflect on what the problem reveals about the underlying concepts.

I aim to develop independent problem-solving skills rather than simply obtain working code.

## Projects and Experiments

AI tools may be used to assist with selected parts of my learning and development workflow. Where applicable, I distinguish my own implementation from AI-assisted components.
