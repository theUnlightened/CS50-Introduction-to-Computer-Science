HTML tags: 1. `html` 2. `head` 3. `body` 4. `link` 5. `script` 6. `meta` 7. `title` 8. `nav` 9. `div` 10. `a` 11. `header` 12. `main` 13. `h1` 14. `p` 15. `table` 16. `thead` 17. `tbody` 18. `tr` 19. `th` 20. `td` 21. `ul` 22. `li` 23. `button` 24. `footer` CSS properties: 1. `font-family`: Sets the font used on the webpage. 2. `text-align`: Aligns the heading text. 3. `line-height`: Controls spacing between lines of text. 4. `background-color`: Sets the background color. 5. `margin`: Sets the outer spacing around an element. 6. `font-size`: Sets the text size. 7. `font-weight`: Controls the thickness of text. JavaScript: I use JavaScript on the homepage to respond to button clicks. Clicking a button changes its background color and displays a feedback message. Bootstrap: I use Bootstrap 5 to style the navigation bar and provide a consistent layout across the four HTML pages. Website structure: - `index.html`: Introduces me and includes a table, a list, and interactive buttons. - `hobbies.html`: Describes my hobby. - `study.html`: Introduces my studies. - `goals.html`: Describes my goals. External CSS: I use `styles.css` to define the font family, heading alignment, paragraph line height, navigation bar background color, introduction margins, and heading appearance.
